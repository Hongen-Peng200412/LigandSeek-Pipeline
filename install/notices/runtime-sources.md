# Scientific sources in libraries.tar.gz

The archive contains the Python modules imported by LigandSeek's Find, Match, Build and input preparation code. `SOURCES.tsv` lists each module's SHA-256 before packaging and its SHA-256 in this archive. In the few files whose hashes differ the packager replaces local workstation paths in documentation and comments. Model definitions, function bodies, registry decorators and their order are retained. The sample configuration and CCD residue tables come from the PocketXMol runtime.
